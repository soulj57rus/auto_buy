# Глиса → Avito: «Купить с доставкой»

Программа следит за **тремя разными списками объявлений в личном кабинете Глисы** и автоматически открывает новые ссылки Avito. На странице объявления она пробует нажать **«Купить с доставкой»**. Telegram, токен бота, `api_id` и `api_hash` не нужны.

## Установка на Arch Linux — одна команда

Если проект ещё не скачан, скопируйте команду из блока ниже (на GitHub у блока есть кнопка копирования):

```bash
sudo pacman -S --needed git && git clone https://github.com/soulj57rus/auto_buy.git && cd auto_buy && bash setup.sh
```

Репозиторий должен быть доступен заказчику и содержать эту версию проекта. Если папка `auto_buy` уже есть, не клонируйте её повторно: используйте команду ниже.

## Если проект уже скачан — запуск или обновление

Откройте терминал **в папке проекта** и скопируйте:

```bash
bash setup.sh
```

Установщик запросит **три разные ссылки на страницы со списками объявлений Глисы**, например адреса вида `http://глиса.рф/личныйкабинет/adlist/123456/`. Их нужно скопировать из адресной строки своего кабинета; **не** ссылки на поиск Avito. Адреса сохраняются в `.env` и повторно не спрашиваются. Если одна ссылка была указана в предыдущей версии, она сохранится — установщик спросит только две оставшиеся. Пароль Глисы в терминале не вводится. Просто `setup.sh` без `bash` или `./` не запускается, поскольку текущая папка не входит в путь поиска команд.

## Вход в аккаунты и наблюдение через localhost

1. Откройте на **этом же компьютере** **http://localhost:6080/vnc.html**. При необходимости нажмите **Connect**.
2. В открывшемся браузере **в первой вкладке Глисы** войдите в свой личный кабинет. Как только первый список станет доступен, программа откроет и две остальные вкладки. **Уже видимые объявления на каждой странице при её первом подключении пропускаются.** Вкладки не закрывайте: все три списка будут обновляться примерно каждые 30 секунд; уведомления сайта программа тоже проверяет.
3. Во вкладке **Avito** войдите в аккаунт. После этого новые объявления будут открываться в отдельных вкладках браузера. Компьютер должен оставаться включённым.

Вход в оба сайта сохраняется в `avito_profile/`; обработанные объявления — в отдельных файлах `data/seen_ads_НОМЕР.json` для каждого списка. История из старого `data/seen_ads.json` будет учтена автоматически. Если одно объявление есть в нескольких списках, программа не нажимает кнопку повторно. **Не удаляйте эти папки**, если хотите сохранить вход и не обрабатывать старые объявления повторно. Эти данные не добавляются в Git; не передавайте их другим людям. Если Глиса завершит сеанс, потребуется войти снова в окне браузера. Обратите внимание: сайт Глисы в предоставленном примере использует **HTTP без шифрования** — вводить пароль на таком сайте небезопасно.

Адрес `localhost:6080` доступен только с этого компьютера и показывает окно браузера, но не отдельную панель состояния. Проверить сообщения программы можно командой из папки проекта:

```bash
sudo docker compose logs -f avito-bot
```

`Ctrl+C` останавливает только просмотр логов, а не саму программу.

**Ограничения:** при изменении интерфейса или формата уведомлений Глисы программа может перестать находить новые объявления. Сохранённый HTML показывает структуру списка, но не даёт проверить живые уведомления. Если объявление не попало на открытую страницу списка и не пришло с прямой ссылкой в уведомлении, оно может быть пропущено. Нажатие **«Купить с доставкой» не гарантирует бронь и не завершает покупку**; оформление и оплату нужно выполнять вручную.

## Полная остановка

Откройте терминал **в папке проекта** и скопируйте:

```bash
sudo docker compose down
```

Контейнер и браузер будут остановлены и после перезагрузки не запустятся сами; сохранённые входы и история останутся. Чтобы снова запустить программу, выполните `bash setup.sh`. Docker как системная служба продолжит работать для других приложений.

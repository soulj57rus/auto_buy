# Глиса → Avito в обычном Chromium

Программа следит за **тремя страницами личного кабинета Глисы** и открывает новые объявления Avito в обычном Chromium на компьютере. Локальное расширение пробует нажать **«Купить с доставкой»**. **Docker, VNC и Telegram не нужны.** Оформление заказа и оплату программа не выполняет.

## Установка на Arch Linux — одна команда

Если проект ещё не скачан, откройте терминал и скопируйте одну строку (на GitHub у блока есть кнопка копирования):

```bash
sudo pacman -S --needed git && git clone https://github.com/soulj57rus/auto_buy.git "$HOME/auto_buy" && bash "$HOME/auto_buy/setup.sh"
```

Репозиторий должен быть доступен заказчику и содержать эту версию проекта. Если проект уже скачан, **не клонируйте его повторно**: откройте терминал в папке проекта и запустите:

```bash
bash setup.sh
```

Установщик ставит Chromium и спрашивает адреса трёх **разных списков объявлений Глисы** вида `http://глиса.рф/личныйкабинет/adlist/123456/`. Ссылки сохраняются в `.env` и повторно не спрашиваются. Установщик создаёт значок **«Глиса — Avito» в меню приложений**. Если старая Docker-версия ещё запущена, останавливается только её контейнер. Ни пароли, ни данные Telegram вводить в терминале не нужно.

## Первый запуск

1. Откроется **обычный Chromium на вашем компьютере**, не окно VNC. Во вкладке Avito войдите в аккаунт и проверьте, открывается ли конкретное объявление без `#block`.
2. Во вкладке Глисы войдите в кабинет. Две другие страницы Глисы откроются автоматически после подключения первой.
3. Вернитесь во вкладку **«Запуск Глиса → Avito»** и нажмите **«Я вошёл в Avito — запустить мониторинг»**. Сделайте это только после входа на Avito. При последующих запусках включённое состояние сохраняется.

Не закрывайте это окно Chromium. Во вкладке **«Запуск Глиса → Avito»** виден большой индикатор: зелёный **«СТАРТ — мониторинг идёт»**, красный **«СТОП — мониторинг остановлен»** или жёлтый **«подключение страниц»**. Там же видны очередь и последнее действие. Кнопка **«Остановить мониторинг»** приостанавливает чтение новых объявлений и автоматические действия, не закрывая браузер; **«запустить мониторинг»** возобновляет их. Объявления, появившиеся за время паузы, будут обработаны после возобновления, если они ещё видны в списках Глисы. Новые ссылки с трёх страниц открываются в отдельных вкладках Avito; если объявление встречается в нескольких списках, оно открывается только один раз. При первом подключении старые видимые объявления каждой страницы пропускаются. Программа обновляет страницы Глисы примерно раз в 30 секунд и также читает их живые уведомления.

**Важно:** Chromium запущен с отдельным профилем `browser_profile/`. Вход в ваш обычный браузер **не переносится**: войти в Глису и Avito в новом окне потребуется один раз. Профиль и настройки расширения сохраняются между запусками; не удаляйте `browser_profile/`. Старые `avito_profile/` и `data/` от Docker-версии не удаляются и новой версией не используются. Если в старой `data/pending_ads.json` были ожидающие объявления, проверьте их вручную: новая версия не переносит эту очередь автоматически.

## Как заказчику запускать и останавливать

После первого запуска откройте **меню приложений** на компьютере и нажмите **«Глиса — Avito»**. Терминал и команды для повседневного запуска не нужны. Если значок не появился, выполните в папке проекта:

```bash
bash start.sh
```

Для обновления настроек сначала закройте отдельный Chromium, затем выполните `bash setup.sh` в папке проекта. Чтобы **полностью остановить программу**, закройте отдельное окно Chromium: пока оно закрыто, мониторинг и автоматические действия не работают.

**Ограничения:** если Avito откажет в доступе обычному Chromium, расширение не сможет гарантировать работу; оно не обходит блокировки. Клик расширения может не сработать на изменившемся сайте — проверяйте открытые вкладки вручную. Нажатие «Купить с доставкой» **не гарантирует бронирование или покупку**. Глиса в предоставленном примере работает через HTTP без шифрования — вводить пароль на таком сайте небезопасно. Не передавайте `browser_profile/` и `.env` другим людям.

# Telegram Web → Avito: «Купить с доставкой»

Программа следит за открытым чатом **в Telegram Web**, находит новые ссылки Avito и нажимает в объявлениях **«Купить с доставкой»**. Получать `api_id` и `api_hash` на my.telegram.org **не нужно**. Это не отдельный Telegram-бот: вы входите в свой аккаунт через официальный сайт в браузере.

## Установка на Arch Linux — скопировать одну команду

Если проект **ещё не скачан**, откройте терминал в домашней папке и скопируйте целиком строку ниже. На GitHub у блока кода есть кнопка копирования:

```bash
sudo pacman -S --needed git && git clone https://github.com/soulj57rus/auto_buy.git && cd auto_buy && bash setup.sh
```

Команда сработает, когда репозиторий по этому адресу доступен заказчику и проект в него загружен. Если папка `auto_buy` уже существует, используйте команду для повторного запуска ниже, а не клонируйте проект заново.

## Если проект уже скачан — запуск или повторный запуск

Нужны интернет и пароль `sudo`. Откройте терминал **в папке проекта** и скопируйте одну команду:

```bash
bash setup.sh
```

Не вводите просто `setup.sh`: текущая папка не входит в путь поиска команд. Установщик поставит Docker, спросит имя бота-источника (по умолчанию `glisa_bot`) и запустит программу. Старый `.env` с `api_id`/`api_hash` не мешает работе: эти значения больше не используются. Не передавайте файл `.env` другим людям.

Если предыдущий запуск завершился ошибкой `project name must not be empty` из-за кириллицы в имени папки, просто повторите `bash setup.sh` с обновлённым `docker-compose.yml`. Настройки вводить повторно не потребуется.

## Первый вход и отслеживание через localhost

1. На этом же компьютере откройте **http://localhost:6080/vnc.html** (при необходимости нажмите **Connect**).
2. В открывшемся браузере выберите вкладку **Telegram Web**. Войдите в свой аккаунт: отсканируйте QR-код приложением Telegram на телефоне или используйте предложенный сайтом вход. Программа попробует открыть чат по указанному username; **проверьте, что открыт именно нужный бот-источник**, и при необходимости откройте его вручную. Оставьте вкладку и этот чат открытыми. Программа запоминает *открытый чат*, но не умеет подтвердить его username по интерфейсу сайта. Старые видимые сообщения при подключении пропускаются.
3. Во вкладке **Avito** войдите в свой аккаунт. Оставьте компьютер включённым и браузер открытым. Новые ссылки из выбранного чата открываются в отдельных вкладках Avito.

Адрес `localhost` доступен **только с этого компьютера**. На нём видно окно браузера (Telegram Web, Avito и новые объявления), но нет отдельной панели состояния или журнала. Чтобы посмотреть, найдена ли ссылка и нажата ли кнопка, откройте терминал в папке проекта и скопируйте:

```bash
sudo docker compose logs -f avito-bot
```

`Ctrl+C` прекращает только просмотр логов, программа продолжит работать.

**Ограничения:** это чтение интерфейса сайта, а не официальный API. При изменении Telegram Web отслеживание может перестать работать; сообщения, не показанные в открытом чате, могут быть пропущены. Не переключайте чат в наблюдаемой вкладке. Нажатие **«Купить с доставкой» не бронирует товар и не завершает покупку**: дальнейшее оформление и оплату нужно выполнить вручную. Наличие кнопки и реакция сайта зависят от объявления.

## Полная остановка программы

Откройте терминал **в папке проекта** и скопируйте:

```bash
sudo docker compose down
```

Эта команда остановит программу и браузер, удалит контейнер и не даст ему запуститься после перезагрузки. Docker как системная служба останется работать — это не повлияет на другие приложения. Чтобы снова запустить программу, выполните `bash setup.sh` в папке проекта.

Вход в оба сайта сохраняется локально в `avito_profile/`: не передавайте эту папку другим людям. Если осталась `data/telegram.session` от старой версии, новая версия её не использует.
